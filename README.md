# Circuits and Expressions Trainer

Practice moving between logic circuits, Boolean expressions and truth tables (OCR A Level Computer Science, H446).

## Features

### Four question types
- **Write the expression** for a circuit
- **Choose the circuit** that matches an expression
- **Find the fault** in a circuit
- **Complete the truth table**

### Options
2, 3 or 4 inputs
- Small (2–3 gates), medium (3–4) or large (5–6) circuits
- Include XOR gates, and label gates if wanted
- Expressions typed with ∧ ∨ ¬ ⊻ buttons or as AND, OR, NOT and XOR; any equivalent answer is accepted
- Right-first-time score

## How to Use

1. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari). Nothing to install, no login.
2. Pick a question type along the top
3. Set the inputs and circuit size, then press **New question**
4. Answer and press **Check**

## Use Cases

- Practice after teaching logic gates
- Quick-fire starters
- Revision

## Tech

- A single HTML file: HTML, CSS and plain JavaScript
- No libraries, no build step, no backend
- Light and dark themes
